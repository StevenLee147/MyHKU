# MyHKU v0.4.2-beta

本次更新全面修复 HKU Moodle 课程抓取不全的问题，新增自定义显示课程管理、Subclass 智能过滤与多维度检索工具栏，并同步推出课程资料本地总目录管理、按「课程代码 / 资料分类」多级智能归档以及远端课件版本更新检测。

## 核心新增与改进

- **Moodle 全量在读课程发现与增量合并保护**：连接器在原有页面 DOM 提取基础上，新增同源只读课程分类接口（覆盖 `allincludinghidden`、`all`、`inprogress`、`future`、`past` 全状态课程）、`/my/courses.php` 与 `/user/profile.php?showallcourses=1` 静态兜底，修复下划线课程代码（如 `GLIS1901_1A_2026`）、无障碍隐藏标签重复文本与课程内分节链接误判问题；同步课程抓取上限提升至 60 门，并在桌面 Bridge 与 Android 原生层启用按课程 `id` / `courseId` 的增量合并保护，杜绝访问局部页面覆盖已有课程缓存。
- **自定义显示课程管理与 Subclass 智能过滤**：新增「管理显示课程」弹窗与快捷命令面板入口，自动识别 `Subclass` / `Tutorial` / `Lab` 子班壳及迎新/学术诚信等非学分系统页，展示每门课的待办、资料与成绩统计，支持逐门勾选显隐、一键隐藏全部 Subclass 或培训页、新课程自动隐藏规则以及课程星标置顶（不影响 SIS 周课表上课安排）。
- **增强型 Moodle 多关键词与多模块检索**：Moodle 页面新增专属检索与筛选工具栏，支持跨空格/连字符课程代码匹配（如输入 `glis 1901 essay` 即时命中 `GLIS1901` 对应作业与课件）、按模块范围（全部 / 课程 / 待办 / 资料 / 成绩 / 公告）、课程类型（常规主课 / Subclass / 星标）、学期与排序方式筛选，并在已隐藏课程存在匹配项时提供一键临时展开提示。
- **课程资料自定义总目录、多级智能归档与更新同步**：首次配置引导页、课程资料页与设置页均支持指定专属课程资料总目录；下载引擎支持 `课程 + 分类归档`（自动提取课程代码并归入 `Course Information`、`Lecture Notes` / `Lecture Slides`、`Tutorials`、`Python Labs`、`Assignments`、`Study_Guides` 等子目录，智能复用本地已有同名或近义目录），并结合本地目录递归索引与远端修订号探测精准标记新增/更新课件，支持一键同步下载与原子覆盖更新。

## 下载与安装

安装包见 [README 下载与设备对应](https://github.com/StevenLee147/MyHKU/blob/main/README.md#下载与设备对应)，详细步骤见 [各设备安装指南](https://github.com/StevenLee147/MyHKU/blob/main/README.md#各设备安装指南)。

- Windows x64：`MyHKU.Setup.0.4.2-beta.exe`（安装版，支持识别旧目录覆盖升级）或 `MyHKU.0.4.2-beta.exe`（便携版）。
- Mac Apple Silicon：`MyHKU-0.4.2-beta-arm64.dmg` 或 `MyHKU-0.4.2-beta-arm64-mac.zip`。
- Android 8.0+：`app-release.apk`（`versionCode` 升至 17，沿用固定发布签名，可在 v0.1.4-alpha 及之后版本上直接覆盖升级）；`app-release.aab` 仅用于商店分发。
- `SHA256SUMS.txt` 提供全部发布产物的 SHA-256 校验值。

本版本为 Beta 预发布版本。macOS 默认采用 ad-hoc 签名，未经 Apple 公证；Windows 尚未使用发布者证书签名。请仅从本仓库 GitHub Releases 下载并核对 `SHA256SUMS.txt`。学校官方系统中的信息始终为最终依据。
