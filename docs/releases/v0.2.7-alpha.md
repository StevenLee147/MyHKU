# MyHKU v0.2.7-alpha

本次更新全面升级课程资料中心，支持按课程一键批量下载、仅下载未存文件队列、桌面端跨重启本地文件路径持久化索引、文件类型智能筛选、常用资料星标置顶与新资料 `NEW` 角标提示。

## 核心新增与改进

- **按课程一键批量下载与队列进度**：每门课程卡片新增「一键全下」与「仅下未存」队列按钮，实时显示当前课程下载进度并支持随时停止队列。
- **本地已下载文件路径跨重启持久化索引**：桌面端自动将已下载课程资料路径持久化保存在本机用户目录（磁盘仍存在时生效，退出账号时同步清空），重启应用后仍可直接点击「打开文件」或「在文件夹中显示」，无需重复下载。
- **资料类型自动识别、筛选与星标置顶**：自动识别并标注 `PDF`、`Slides`、`Word`、`Excel`、`ZIP`、`文件夹` 与 `链接` 类型标签，顶部支持按类型、待下载与星标快速过滤；支持将重点大纲与讲义星标置顶至对应课程顶部。
- **新增资料 `NEW` 角标与一键已读**：首次同步自动建立已见基线，后续同步发现的新上传课件自动展示 `NEW` 角标，点击下载、查看或「全部标为已读」后自动消去。

## 下载与安装

安装包见 [README 下载与设备对应](https://github.com/StevenLee147/MyHKU/blob/main/README.md#下载与设备对应)，详细步骤见 [各设备安装指南](https://github.com/StevenLee147/MyHKU/blob/main/README.md#各设备安装指南)。

- Windows x64：`MyHKU.Setup.0.2.7-alpha.exe`（安装版，支持识别旧目录覆盖升级）或 `MyHKU.0.2.7-alpha.exe`（便携版）。
- Mac Apple Silicon：`MyHKU-0.2.7-alpha-arm64.dmg` 或 `MyHKU-0.2.7-alpha-arm64-mac.zip`。
- Android 8.0+：`app-release.apk`（`versionCode` 升至 12，沿用固定发布签名，可在 v0.1.4-alpha 及之后版本上直接覆盖升级）；`app-release.aab` 仅用于商店分发。
- `SHA256SUMS.txt` 提供全部发布产物的 SHA-256 校验值。

本版本为 Alpha 预发布版本。macOS 默认采用 ad-hoc 签名，未经 Apple 公证；Windows 尚未使用发布者证书签名。请仅从本仓库 GitHub Releases 下载并核对 `SHA256SUMS.txt`。学校官方系统中的信息始终为最终依据。
