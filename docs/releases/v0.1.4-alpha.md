# MyHKU v0.1.4-alpha

修复 Android 下载包提示“应用未安装 / 安装包无效”的发布问题，以及桌面版 Portal 登录成功后状态更新缓慢、阻塞 SIS/Moodle、仪表盘仍显示未成功的问题。

- Android 改为固定密钥签名的 `app-release.apk`，停止发布无法直接安装的未签名 APK。签名配置缺失时构建失败，不再退回每次不同的调试签名。
- 发布前校验 APK 签名、固定证书、版本、兼容性和对齐，并在 Android 8.0、Android 15 模拟器实际安装、覆盖升级及启动应用。Android `versionCode` 升至 4，版本名与桌面版一致。

- Portal 直接根据已渲染的登录后页面确认成功，不再等待图片、iframe 或整个页面加载完成。确认后立即通知仪表盘并继续后续服务。
- 超时、加载失败或等待 MFA 时释放自动登录队列；原窗口继续检测，手动完成验证或迟到的 CAS 回调可以恢复连接。
- SIS 从 Portal 的实际入口建立会话，识别嵌套和跨域课表框架；SIS 首页确认成功后即可继续 Moodle，课表读取独立进行。
- 防止迟到的旧状态覆盖最新登录结果；验证横幅、侧栏和服务连接状态统一更新，遗漏事件时可自动恢复。
- 官方退出后停止自动填写密码；注销、修改凭据或切换账户时清理旧窗口和会话，旧检测不能影响新账户。
- Windows 和 macOS 发布前均执行桌面登录回归测试。

回归覆盖 8 项队列测试、36 项 Chromium 页面用例、仪表盘测试及生产主进程/preload 集成测试。测试使用独立配置和模拟官方页面，未以真实 HKU 账户完成学校 MFA 验证。

## 下载与安装

最新安装包见 [README 下载与设备对应](https://github.com/StevenLee147/MyHKU/blob/main/README.md#下载与设备对应)，安装步骤见 [各设备安装指南](https://github.com/StevenLee147/MyHKU/blob/main/README.md#各设备安装指南)。

- Windows x64：推荐 `MyHKU.Setup.0.1.4-alpha.exe`；免安装版为 `MyHKU.0.1.4-alpha.exe`。
- Mac Apple Silicon：下载 `MyHKU-0.1.4-alpha-arm64.dmg` 或 `MyHKU-0.1.4-alpha-arm64-mac.zip`。
- Android 8.0+：下载已签名的 `app-release.apk`；AAB 用于分发而非直接安装。未安装过 MyHKU 的设备可直接安装。
- `SHA256SUMS.txt` 提供下载文件的 SHA-256 校验值。

这是 alpha 预发布版本。macOS 默认包采用 ad-hoc 签名，未进行 Apple 公证；首次安装的系统提示处理方法见安装指南。

若已安装 v0.1.1/v0.1.2 的旧调试包，其签名与新包不同，无法直接覆盖。请先保存需要的资料和设置，再卸载旧测试版安装本版；卸载会清除旧版本的本地数据。此后固定签名版本可正常覆盖升级。
