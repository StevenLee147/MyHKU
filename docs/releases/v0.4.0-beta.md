# MyHKU v0.4.0-beta

本次更新完成可靠分发与本地诊断自愈里程碑，新增应用内 GitHub Releases 新版检查与跨平台安装包直达指引、连接健康度与分区缓存重建面板，以及本地自建待办与 GPA 配置 JSON 备份/合并恢复功能。

## 核心新增与改进

- **应用内版本更新检查与对应设备下载指引**：设置页新增只读查询本仓库 GitHub Releases 的更新检查器，遵循 SemVer 2.0 精确比对预发布与正式版本，自动匹配当前运行设备（Windows 安装版 EXE、macOS Apple Silicon DMG 或 Android 签名 APK）并提供更新摘要与 `SHA256SUMS.txt` 校验入口。
- **同步健康诊断与分区缓存自愈**：设置页直观展示已连接服务数、已缓存课表周数、课堂记录数、Moodle 课程/资料数以及官方作业/个人自建日程统计；本地桥接与前端缓存新增按分区（`schedule` / `moodle`）重置支持，无需退出登录或丢失其他数据即可「仅重建课表缓存」或「仅重抓 Moodle 状态」。
- **本地学习配置 JSON 备份与合并恢复**：支持将个人自建待办/考试倒计时、HKU 4.3 GPA 模拟权重/目标等级、常用资料星标及外观/语言偏好一键导出为标准 `myhku-learning-backup-v1` JSON 文件并在跨设备或重装后合并恢复；导入导出全程严格排除并拦截任何账号密码、Cookie 或令牌字段。

## 下载与安装

安装包见 [README 下载与设备对应](https://github.com/StevenLee147/MyHKU/blob/main/README.md#下载与设备对应)，详细步骤见 [各设备安装指南](https://github.com/StevenLee147/MyHKU/blob/main/README.md#各设备安装指南)。

- Windows x64：`MyHKU.Setup.0.4.0-beta.exe`（安装版，支持识别旧目录覆盖升级）或 `MyHKU.0.4.0-beta.exe`（便携版）。
- Mac Apple Silicon：`MyHKU-0.4.0-beta-arm64.dmg` 或 `MyHKU-0.4.0-beta-arm64-mac.zip`。
- Android 8.0+：`app-release.apk`（`versionCode` 升至 15，沿用固定发布签名，可在 v0.1.4-alpha 及之后版本上直接覆盖升级）；`app-release.aab` 仅用于商店分发。
- `SHA256SUMS.txt` 提供全部发布产物的 SHA-256 校验值。

本版本为 Beta 预发布版本。macOS 默认采用 ad-hoc 签名，未经 Apple 公证；Windows 尚未使用发布者证书签名。请仅从本仓库 GitHub Releases 下载并核对 `SHA256SUMS.txt`。学校官方系统中的信息始终为最终依据。
