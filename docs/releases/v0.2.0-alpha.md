# MyHKU v0.2.0-alpha

本次更新修复桌面版课表日期、Moodle 作业信息和课程资料下载，并改进学习数据展示。

- 课表使用 HKU MyWeekly 官方入口。修复跨行单元格导致的星期错位，按课程日期定位，并保留原始课程名称、时间和地点。
- 课表时间和地点分行显示，支持自动换行；时间轴涵盖早晚课程。
- 今日课程按香港日期统计，修复错误显示 0 节及超过 3 节时计数被截断的问题。
- 课程资料按课程分栏。桌面版复用 Moodle 登录会话，将文件直接保存至下载文件夹，不弹出原始页面；重名文件自动编号。
- 从各课程的 Activities 汇总页读取作业截止时间和提交状态，正确区分已提交、未提交和草稿；修复旧缓存重复记录和部分刷新覆盖已有作业详情的问题。
- Android 版本更新至 0.2.0-alpha，versionCode 升至 5，沿用固定签名；发布流程验证从 0.1.4-alpha 覆盖升级。

## 验证

发布前执行前端构建、隐私检查、课表/作业/资料 Chromium 回归，以及桌面主进程和登录集成测试。课表样例覆盖 11 节课程，包含周二 1 节和周四 4 节；下载测试验证实际文件内容及重名文件保留。Windows 和 macOS 均执行这些回归，Android 在 8.0 和 15 模拟器检查安装、升级和启动。

数据解析回归使用隔离的本地页面样例，未使用真实 HKU 账户进行线上核验。Android 原生数据采集和下载流程不包含本次桌面端连接器修复。

## 下载与安装

安装包见 [README 下载与设备对应](https://github.com/StevenLee147/MyHKU/blob/main/README.md#下载与设备对应)，安装步骤见 [各设备安装指南](https://github.com/StevenLee147/MyHKU/blob/main/README.md#各设备安装指南)。

- Windows x64：`MyHKU.Setup.0.2.0-alpha.exe`（安装版）或 `MyHKU.0.2.0-alpha.exe`（便携版）。
- Mac Apple Silicon：`MyHKU-0.2.0-alpha-arm64.dmg` 或 `MyHKU-0.2.0-alpha-arm64-mac.zip`。
- Android 8.0+：`app-release.apk`；`app-release.aab` 仅用于分发。
- `SHA256SUMS.txt` 提供安装包校验值。

更新桌面版后点击“立即刷新”，重新获取课表及 Moodle 作业信息。这是 alpha 预发布版本；macOS 默认采用 ad-hoc 签名，首次安装提示的处理方法见安装指南。
