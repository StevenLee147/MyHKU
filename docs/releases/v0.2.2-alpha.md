# MyHKU v0.2.2-alpha

本次更新完成桌面端、Android 端、本地桥接与前端仪表盘的系统性重构与问题修复，补齐课程下钻、多周课表预抓、本地截止提醒、账号清理及深浅色主题。

## 核心修复与改进

- **Android 仪表盘白屏与原生桥接重构**：接入 `WebViewAssetLoader` 承载内置前端资源，解决 `file://` ES Module 跨域拦截导致的白屏问题；默认首屏进入 React 仪表盘并按需弹出官方认证页，对齐 `myhkuAndroid` 数据接口与事件推送，统一注入共享只读连接器，新增系统返回键导航与带会话认证的课程资料下载。
- **账号切换与退出全链路缓存清理**：在顶栏用户菜单和设置页提供「修改账号凭据」与「退出账号并清除缓存」入口（兼容 `@connect.hku.hk` 与 `@hku.hk` 邮箱）；注销或切换账号时原子清理本地桥接内存快照、磁盘加密缓存、官方 WebView 会话分区及浏览器本地缓存。
- **SIS 多周课表预抓与按周分区缓存**：同步时自动预抓当前周及后续多周课表，桥接服务按周日期区间分区替换合并，查看或更新其他周课表不再覆盖首页「今日课程」；同一时段冲突课程改为并排分列展示，不再互相遮挡。
- **Moodle 课程详情下钻与成绩状态精细化**：点击任意课程可按单门课程查看公告、作业待办、成绩与资料；受控并发抓取课程页与 Overview 页，准确区分「未发布 (`-`)」、数值 `0` 分、百分比分数与等级制成绩。
- **全局搜索、本地提醒、下载直达与深浅色主题**：支持 `Ctrl+K` / `⌘K` 跨页面实时过滤课程、课表、待办与资料；补齐作业截止前 24 小时 / 1 小时去重提醒及课表增删变更检测；桌面端下载完成后支持直接打开文件或打开所在文件夹；新增跟随系统、浅色与深色三种外观模式，并严格隔离多页面演示数据与真实缓存。
- **CDP 连接器、浏览器扩展与发布工作流修复**：修复 `bridge:cdp` 入口包装与异步提取逻辑，为 Chrome 扩展补齐 `sweb.hku.hk` 与 `intraweb.hku.hk` 课表域名权限；锁定全部构建依赖版本，并在发布流水线中自动解析最新已发布安装包验证 Windows 与 Android 覆盖升级。

## 下载与安装

安装包见 [README 下载与设备对应](https://github.com/StevenLee147/MyHKU/blob/main/README.md#下载与设备对应)，详细步骤见 [各设备安装指南](https://github.com/StevenLee147/MyHKU/blob/main/README.md#各设备安装指南)。

- Windows x64：`MyHKU.Setup.0.2.2-alpha.exe`（安装版，支持识别旧目录覆盖升级）或 `MyHKU.0.2.2-alpha.exe`（便携版）。
- Mac Apple Silicon：`MyHKU-0.2.2-alpha-arm64.dmg` 或 `MyHKU-0.2.2-alpha-arm64-mac.zip`。
- Android 8.0+：`app-release.apk`（`versionCode` 升至 7，沿用固定发布签名，可在 v0.2.1-alpha 上直接覆盖升级）；`app-release.aab` 仅用于商店分发。
- `SHA256SUMS.txt` 提供全部发布产物的 SHA-256 校验值。

本版本为 Alpha 预发布版本。macOS 默认采用 ad-hoc 签名，未经 Apple 公证；Windows 尚未使用发布者证书签名。请仅从本仓库 GitHub Releases 下载并核对 `SHA256SUMS.txt`。学校官方系统中的信息始终为最终依据。
