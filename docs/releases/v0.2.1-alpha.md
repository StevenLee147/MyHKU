# MyHKU v0.2.1-alpha

本次更新统一应用标识，并完善安装、覆盖升级和使用协议。

- 原创「书本 M · 星芒」Logo 应用于 Windows EXE/安装器、macOS App/DMG、Android 自适应图标、网页和浏览器连接器。
- Windows 安装版改为分步向导，可选择安装目录；再次运行新版安装包会识别旧安装位置并替换程序，保留本地账户、会话、缓存和偏好。
- Android 保持原包名及固定发布签名，versionCode 提升为 6；可以在 v0.2.0-alpha 上直接覆盖安装，保留应用数据。
- macOS 保持原 Bundle ID；退出旧版本后，将新版 MyHKU.app 放入原目录并确认「替换」，保留用户数据。可以在 Finder 中选择 Applications 或其他有权限的文件夹。ZIP 和 Windows 便携版需自行替换原程序文件。
- 增加用户协议、隐私说明和免责声明。Windows 安装向导、macOS DMG 和各端首次启动提供协议；三项均确认后才开启账户、官方登录和同步。确认记录保存在本机，协议版本变化时重新确认，可在设置中重读。
- 发布流程使用真实 v0.2.0-alpha 安装包验证 Windows 和 Android 覆盖升级；Android 在 8.0 与 15 模拟器验证安装和启动。

## 安装与更新

Windows 推荐 `MyHKU.Setup.0.2.1-alpha.exe`；Mac M 系列使用 `MyHKU-0.2.1-alpha-arm64.dmg`；Android 使用 `app-release.apk`。无需卸载现有正式签名版本。系统可能要求确认替换或安装；本次未加入后台下载或静默自动更新服务。

完整操作见 [各设备安装指南](https://github.com/StevenLee147/MyHKU#各设备安装指南)。Windows 便携版与 macOS ZIP 备用包均在首次运行时显示协议。Android 旧临时调试签名版本仍无法与发布版互相覆盖。

本版本为 Alpha 预发布。macOS 默认 ad-hoc 签名，未经 Apple 公证；Windows 仍未使用发布者证书签名。请从本项目 Releases 下载，并使用 `SHA256SUMS.txt` 校验文件。学校系统中的信息始终为最终依据。
