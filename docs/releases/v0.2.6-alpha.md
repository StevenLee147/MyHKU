# MyHKU v0.2.6-alpha

本次更新围绕 HKU 学生的日常日程规划与考试季复习场景，新增标准 `.ics` 课表与待办一键日历导出，以及自建待办 / 小测 / 考试倒计时 / Project 里程碑管理。

## 核心新增与改进

- **课表与 DDL 标准 `.ics` 日历一键导出**：支持将已缓存的多周 SIS 课表及未完成的 Moodle 作业、自建考试/DDL 事项生成符合 RFC 5545 标准的 `.ics` 日历文件（绑定 `Asia/Hong_Kong` 时区，内置课前 15 分钟及截止前 24 小时 / 1 小时 `VALARM` 提醒），可直接导入 Apple Calendar、Google Calendar 与 Outlook。
- **自建待办与考试倒计时管理**：支持在概览页、课表页与 Moodle 页随时新建、编辑、勾选完成和删除自定义事项（涵盖自建作业、小测 Quiz、考试 Exam、课程 Project 四类标签及考场备注），采用原生无障碍 `<dialog>` 弹窗，并与官方 Moodle 作业统一按截止时间排序与触发本地提醒。
- **周课表当周到期事项提示条**：在周课表顶部自动汇总并展示当前浏览周内即将截止的官方作业与自建考试/DDL 标记；退出账号时同步清理本地自建事项以保障多账号隐私隔离。

## 下载与安装

安装包见 [README 下载与设备对应](https://github.com/StevenLee147/MyHKU/blob/main/README.md#下载与设备对应)，详细步骤见 [各设备安装指南](https://github.com/StevenLee147/MyHKU/blob/main/README.md#各设备安装指南)。

- Windows x64：`MyHKU.Setup.0.2.6-alpha.exe`（安装版，支持识别旧目录覆盖升级）或 `MyHKU.0.2.6-alpha.exe`（便携版）。
- Mac Apple Silicon：`MyHKU-0.2.6-alpha-arm64.dmg` 或 `MyHKU-0.2.6-alpha-arm64-mac.zip`。
- Android 8.0+：`app-release.apk`（`versionCode` 升至 11，沿用固定发布签名，可在 v0.1.4-alpha 及之后版本上直接覆盖升级）；`app-release.aab` 仅用于商店分发。
- `SHA256SUMS.txt` 提供全部发布产物的 SHA-256 校验值。

本版本为 Alpha 预发布版本。macOS 默认采用 ad-hoc 签名，未经 Apple 公证；Windows 尚未使用发布者证书签名。请仅从本仓库 GitHub Releases 下载并核对 `SHA256SUMS.txt`。学校官方系统中的信息始终为最终依据。
