# MyHKU v0.4.4-beta

本次更新重点修复桌面端（Windows / macOS）在全量已选课程发现开启后无法完整同步全部 Moodle 课程与课程资料、导致概览 / Moodle / 课程资料页面仅残留旧版缓存课程的问题，并全面增强多课程抓取速度与资料完整性。

## 核心修复与改进

- **修复桌面端多课程大模型同步被浏览器引擎拦截的问题**：此前桌面端在官方 Moodle 页面渲染进程内直接通过 `fetch(..., { keepalive: true })` 向本地桥接提交同步数据；当全量已选课程及课件列表超过 Chromium `keepalive` 64 KiB 负载上限（或触发 HTTPS → 本地回环混合内容 / LNA 限制）时，请求被静默拒绝，导致桌面端停留在旧版部分课程缓存而与手机端课程数不一致。现改为由 Electron 主进程直接读取只读解析结果并投递至本地桥接，彻底解除 64 KiB 负载限制与跨源回环限制，同时对浏览器扩展模式补充字节阈值动态 `keepalive` 与 `targetAddressSpace: 'loopback'` 声明。
- **桌面端与移动端两阶段渐进式秒级课程同步**：连接或点击刷新后，先在亚秒级内同步并渲染完整已选课程列表（支持 `core_course_get_enrolled_courses_by_timeline_classification` 自动分页突破 200 门上限，并兼容从任意 Moodle 子页面触发 `/my/courses.php` 与 `/user/profile.php?showallcourses=1` 兜底发现），随后并行抓取最多 120 门课程的详情与资料。
- **补齐多章节 / 折叠课程资料抓取与下划线课程代码归档**：抓取课程时并行解析 `/course/overview.php` 与 `/mod/assign/index.php`，新增对 Moodle 5 课程概览页、`/course/resources.php` 资料索引页、`/mod/book/` 及直接 `pluginfile.php` 课件链接的提取；修复下划线格式课程名（如 `CAES1001_1`、`GLIS1901_1A_2026`）在课程资料归档目录中的课程代码提取，并自动清理历史缓存中的 `Course name` 无障碍前缀；本地桥接单类条目上限提升至 5,000 项。

## 下载与安装

安装包见 [README 下载与设备对应](https://github.com/StevenLee147/MyHKU/blob/main/README.md#下载与设备对应)，详细步骤见 [各设备安装指南](https://github.com/StevenLee147/MyHKU/blob/main/README.md#各设备安装指南)。

- Windows x64：`MyHKU.Setup.0.4.4-beta.exe`（安装版，支持识别旧目录覆盖升级）或 `MyHKU.0.4.4-beta.exe`（便携版）。
- Mac Apple Silicon：`MyHKU-0.4.4-beta-arm64.dmg` 或 `MyHKU-0.4.4-beta-arm64-mac.zip`。
- Android 8.0+：`app-release.apk`（`versionCode` 升至 19，沿用固定发布签名，可在 v0.1.4-alpha 及之后版本上直接覆盖升级）；`app-release.aab` 仅用于商店分发。
- `SHA256SUMS.txt` 提供全部发布产物的 SHA-256 校验值。

本版本为 Beta 预发布版本。macOS 默认采用 ad-hoc 签名，未经 Apple 公证；Windows 尚未使用发布者证书签名。请仅从本仓库 GitHub Releases 下载并核对 `SHA256SUMS.txt`。学校官方系统中的信息始终为最终依据。
