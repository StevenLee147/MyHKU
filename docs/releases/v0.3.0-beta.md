# MyHKU v0.3.0-beta

本次更新正式迈入 Beta 里程碑，新增 HKU 官方 4.3 制学期与累计 GPA 模拟器、单门课程平时分权重与目标等级 What-if 试算器，以及覆盖全应用页面的简体中文 / English 实时双语切换。

## 核心新增与改进

- **HKU 4.3 制学期 GPA 与累计 CGPA 模拟器**：内置港大官方 4.3 绩点映射（`A+` = 4.3、`A` = 4.0、`A-` = 3.7 … `D` = 1.0、`F` = 0.0，自动跳过 `P` 不计绩点学分），支持录入往期已修学分与累计 CGPA，按当前同步课程实时模拟预测本学期 GPA 与累计 CGPA。
- **单门课程平时分加权与目标等级试算 (What-if Calculator)**：在任意课程详情页自动接入已发布的分数、百分比或比例成绩（如 `42 / 50`、`88.5%`），支持自由设置各项考核权重与试算分数，即时计算已获加权分与达成目标等级（如 `A` / `A+`）在剩余考核权重中所需的均分线。
- **全应用简体中文 / English 一键实时切换**：在顶栏与设置页新增语言切换开关，覆盖侧栏导航、概览页、周课表、Moodle 课程与成绩页、课程资料中心与设置面板，同步更新文档 `lang` 无障碍属性并本地持久化偏好。

## 下载与安装

安装包见 [README 下载与设备对应](https://github.com/StevenLee147/MyHKU/blob/main/README.md#下载与设备对应)，详细步骤见 [各设备安装指南](https://github.com/StevenLee147/MyHKU/blob/main/README.md#各设备安装指南)。

- Windows x64：`MyHKU.Setup.0.3.0-beta.exe`（安装版，支持识别旧目录覆盖升级）或 `MyHKU.0.3.0-beta.exe`（便携版）。
- Mac Apple Silicon：`MyHKU-0.3.0-beta-arm64.dmg` 或 `MyHKU-0.3.0-beta-arm64-mac.zip`。
- Android 8.0+：`app-release.apk`（`versionCode` 升至 13，沿用固定发布签名，可在 v0.1.4-alpha 及之后版本上直接覆盖升级）；`app-release.aab` 仅用于商店分发。
- `SHA256SUMS.txt` 提供全部发布产物的 SHA-256 校验值。

本版本为 Beta 预发布版本。macOS 默认采用 ad-hoc 签名，未经 Apple 公证；Windows 尚未使用发布者证书签名。请仅从本仓库 GitHub Releases 下载并核对 `SHA256SUMS.txt`。学校官方系统中的信息始终为最终依据。
