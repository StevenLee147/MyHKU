# MyHKU v0.2.4-alpha

本次更新修复 SIS 课表整体偏移一天（左移一天）的问题，并为 Android 手机端与移动网页补齐顶部/底部系统安全区边界与触控尺寸适配。

## 核心修复与改进

- **修复 SIS `MyWeekly` 课表日期整体左移一天**：`sweb.hku.hk` 的 `MyWeekly` 课表表头 `table.bkgCalViewbg` 采用折叠边框，使前一列右边界略大于下一列绝对定位课程块的 `left: 13em..53em` 像素起点，导致原左边缘匹配将周一至周五课程整体归入前一天。现改为基于课程块水平中心点匹配表头列区间，并为离线 `DOMParser` 预抓补充 `3em + 7 × 10em` 网格坐标回退，兼容同一时段并排半宽冲突课程。
- **纯日历日期运算与旧版错位缓存自动迁移**：前端课表服务改用无时区漂移的纯日历分量（优先原生 `Temporal.PlainDate`，回退确定性 UTC 日历整数差值）替代手工拼接 ISO 时间字符串，并将桌面加密桥接缓存、Android 原生快照与前端本地缓存的 `scheduleSchema` 升至 `2`，升级后自动清理旧版错位周课表同时完整保留已缓存的 Moodle 课程、作业、资料与成绩。
- **Android 手机端顶部/底部系统 UI 安全边界**：针对 Android 15（`targetSdk = 35`）默认强制 Edge-to-Edge 导致顶栏与底栏被状态栏、挖孔摄像头及系统导航栏遮挡无法点击的问题，在 `MainActivity` 统一接入 `WindowInsetsCompat`（`systemBars | displayCutout | ime`）上下安全边界容器并联动深浅色状态栏/导航栏图标对比度，覆盖首次使用协议页、React 仪表盘及官方认证 WebView 工具栏。
- **移动端 CSS 安全区与触控目标加固**：启用 `viewport-fit=cover`，为顶栏、侧滑抽屉顶/底栏、主内容区、弹窗及提示条注入 `env(safe-area-inset-*)` 内边距与 `scroll-padding`，并在触屏设备（`pointer: coarse`）下保证关键操作按钮具备不少于 `44×44px` 的可点击热区。

## 下载与安装

安装包见 [README 下载与设备对应](https://github.com/StevenLee147/MyHKU/blob/main/README.md#下载与设备对应)，详细步骤见 [各设备安装指南](https://github.com/StevenLee147/MyHKU/blob/main/README.md#各设备安装指南)。

- Windows x64：`MyHKU.Setup.0.2.4-alpha.exe`（安装版，支持识别旧目录覆盖升级）或 `MyHKU.0.2.4-alpha.exe`（便携版）。
- Mac Apple Silicon：`MyHKU-0.2.4-alpha-arm64.dmg` 或 `MyHKU-0.2.4-alpha-arm64-mac.zip`。
- Android 8.0+：`app-release.apk`（`versionCode` 升至 9，沿用固定发布签名，可在 v0.1.4-alpha 及之后版本上直接覆盖升级）；`app-release.aab` 仅用于商店分发。
- `SHA256SUMS.txt` 提供全部发布产物的 SHA-256 校验值。

本版本为 Alpha 预发布版本。macOS 默认采用 ad-hoc 签名，未经 Apple 公证；Windows 尚未使用发布者证书签名。请仅从本仓库 GitHub Releases 下载并核对 `SHA256SUMS.txt`。学校官方系统中的信息始终为最终依据。
