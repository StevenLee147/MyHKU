# MyHKU v0.2.5-alpha

本次更新重点修复 Moodle Assessment 截止时间误抓开放时间（`Opened`）以及未提交作业被误判为已完成的问题，并扩展 Quiz / Turnitin 及单作业详情页的状态回退与缓存自动迁移。

## 核心修复与改进

- **精准剥离 `Opened` 开放时间与 `Due` 截止时间**：重构四端共享连接器、本地桥接与前端通知服务的时间解析逻辑，优先识别 `Due`、`Closes`、`截止`、`到期` 等明确标签并自动剔除 `Opened` 开放时间片段，彻底解决课程卡片同时展示开放与截止日期时错拿开放时间的问题。
- **消除提交状态假阳性误判**：移除对整个活动卡片文本盲目匹配 `completed` / `submitted` 子串的回退逻辑，避免标题或说明包含相关词汇（如 `Submit completed form`）的未交作业被误判为已完成；改为严格依据提交状态单元格与 Moodle 完成度徽章（`Done` / `To do`）判定，统一规范化提交状态展示。
- **扩展 Quiz / Turnitin 提取与单作业详情页回退**：新增 `/mod/quiz/` 与 `/mod/turnitintooltwo/` 评估项提取，并在 `/course/overview.php` 之外补充 `/mod/assign/index.php` 汇总表及单作业详情页（`/mod/assign/view.php`）有界并发只读回抓，采用字段级非空择优合并保留完整年份与提交状态。
- **旧版错乱作业缓存自动迁移**：将前端本地缓存、桌面加密桥接缓存与 Android 原生快照的 `assignmentSchema` 升至 `2`，升级后自动清理旧版错乱的作业状态缓存并保留已同步的课表、课程、资料与成绩。

## 下载与安装

安装包见 [README 下载与设备对应](https://github.com/StevenLee147/MyHKU/blob/main/README.md#下载与设备对应)，详细步骤见 [各设备安装指南](https://github.com/StevenLee147/MyHKU/blob/main/README.md#各设备安装指南)。

- Windows x64：`MyHKU.Setup.0.2.5-alpha.exe`（安装版，支持识别旧目录覆盖升级）或 `MyHKU.0.2.5-alpha.exe`（便携版）。
- Mac Apple Silicon：`MyHKU-0.2.5-alpha-arm64.dmg` 或 `MyHKU-0.2.5-alpha-arm64-mac.zip`。
- Android 8.0+：`app-release.apk`（`versionCode` 升至 10，沿用固定发布签名，可在 v0.1.4-alpha 及之后版本上直接覆盖升级）；`app-release.aab` 仅用于商店分发。
- `SHA256SUMS.txt` 提供全部发布产物的 SHA-256 校验值。

本版本为 Alpha 预发布版本。macOS 默认采用 ad-hoc 签名，未经 Apple 公证；Windows 尚未使用发布者证书签名。请仅从本仓库 GitHub Releases 下载并核对 `SHA256SUMS.txt`。学校官方系统中的信息始终为最终依据。
