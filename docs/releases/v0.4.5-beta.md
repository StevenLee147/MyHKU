# MyHKU v0.4.5-beta

本次更新重点修复已下载课程资料被误识别为「有更新」、部分文件点击下载无响应或归档至错误目录的问题，并新增独立的**下载队列**页面与全局并发下载调度器。

## 核心修复与新增功能

- **修复已下载及刚下载文件被误判为「有更新」的问题**：
  - 解除 HTTP 压缩传输与 Chromium 磁盘缓存对 `Content-Length` 响应头的漂移影响：此前远端流式/压缩下载时响应头不含明文 `Content-Length`，而后续探测命中缓存时合成了 `Content-Length`，导致刚下载完成的文件签名即刻不一致；现改为优先基于规范化 URL、修订号、`ETag`（Moodle SHA-1 内容摘要）与 `Last-Modified` 生成稳定签名，并向后兼容旧版 4 段缓存签名。
  - 修复本地已有课程目录扫描的跨课程兜底误匹配：禁止尚未建夹的新课程回退匹配其他课程目录下的同名文件（如 `Syllabus.pdf`、`Lecture 1.pdf`），增加扩展名一致性校验、Moodle `ETag` 与本地文件 SHA-1 内容哈希直验、以及 `Last-Modified` 时间先后比对，彻底杜绝将本地批注过或刚保存的文件误报为远端有更新。
  - 消除后台探测与下载操作的竞态覆盖，移除 Moodle 文件夹探测 12 个文件的截断偏差，过滤无障碍 `.accesshide` 后缀引发的假性标题变更，并在升级后自动清理旧版残留的误报标记。
- **修复点击下载无响应、连接抢占及归档落盘异常**：
  - 远端更新探测仅针对本地已下载文件发起请求（未下载资料零网络探测），并在用户发起下载时自动让出连接通道；单文件直链下载采用懒加载 HTML 解析器，免除每次点击创建隐藏窗口的延迟。
  - 补齐 Moodle 弹窗/中转模式资源的 `?redirect=1` 自动跟随兜底、`webservice/pluginfile.php` 与媒体/图片课件链接解析、文件夹内多文件独立落盘（避免将单文件替换路径误套用到多文件目录）、中文 `Content-Disposition` 乱码恢复及超长文件名扩展名保留；Windows 下遇到目标文件被阅读器占用时自动安全另存，Moodle 会话过期时自动触发后台重连并重试。
- **新增「下载队列」页面与全局传输中心**：
  - 侧边导航栏与快捷命令面板（`Ctrl/⌘ + K`）新增「下载队列」视图，切换任意页面均不中断后台下载。
  - 实时展示进行中/排队中/已完成/失败统计、单文件及多文件进度条、已接收字节数、目标归档完整路径与失败原因；支持暂停/恢复队列、单任务取消、一键重试失败项、清空已完成记录，以及直接打开本地文件或定位所在文件夹；Moodle 页面资料行现亦支持直接一键加入下载队列。

## 下载与安装

安装包见 [README 下载与设备对应](https://github.com/StevenLee147/MyHKU/blob/main/README.md#下载与设备对应)，详细步骤见 [各设备安装指南](https://github.com/StevenLee147/MyHKU/blob/main/README.md#各设备安装指南)。

- Windows x64：`MyHKU.Setup.0.4.5-beta.exe`（安装版，支持识别旧目录覆盖升级）或 `MyHKU.0.4.5-beta.exe`（便携版）。
- Mac Apple Silicon：`MyHKU-0.4.5-beta-arm64.dmg` 或 `MyHKU-0.4.5-beta-arm64-mac.zip`。
- Android 8.0+：`app-release.apk`（`versionCode` 升至 20，沿用固定发布签名，可在 v0.1.4-alpha 及之后版本上直接覆盖升级）；`app-release.aab` 仅用于商店分发。
- `SHA256SUMS.txt` 提供全部发布产物的 SHA-256 校验值。

本版本为 Beta 预发布版本。macOS 默认采用 ad-hoc 签名，未经 Apple 公证；Windows 尚未使用发布者证书签名。请仅从本仓库 GitHub Releases 下载并核对 `SHA256SUMS.txt`。学校官方系统中的信息始终为最终依据。
