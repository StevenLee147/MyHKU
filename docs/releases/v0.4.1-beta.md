# MyHKU v0.4.1-beta

本次更新重构完整周课表视图，将每小时行高精简至 `56px`、移除冗余的 30 分钟细分辅助线并引入当周时段智能收敛，使桌面端一屏即可完整浏览全周课程，同时升级 6 套明暗双模式高对比课程配色与香港时区实时时间指示线。

## 核心新增与改进

- **紧凑整点周课表与智能时段收敛**：完整周视图由原先固定的 `120px/小时` 与 `08:00–19:00` 长画布精简为 `56px/小时` 整点单线刻度，默认展示 `09:00–18:00` 核心时段并按当周早课（如 `08:30`）或晚课（如 `20:50`）自动扩展边界，纵向总高度缩减约 60%，桌面视口无需大幅纵向滚动即可总览全周。
- **同课程确定性色彩编码与自适应卡片排版**：按课程代码（如 `COMP7901` Lecture / Tutorial / Lab）自动归组映射 6 套浅色与深色双主题学术配色，搭配内嵌圆角色条；针对 50 分钟短课时自动切换紧凑双行信息排版，消除窄列或短课时卡片内部滚动条。
- **香港时区实时时间线与今日列聚焦**：表头重构为星期与日期数字双层等宽排版，新增「今天」胶囊徽章、周末柔和底纹，以及在当周今日列每分钟刷新的 `Asia/Hong_Kong` 实时进度指示线。

## 下载与安装

安装包见 [README 下载与设备对应](https://github.com/StevenLee147/MyHKU/blob/main/README.md#下载与设备对应)，详细步骤见 [各设备安装指南](https://github.com/StevenLee147/MyHKU/blob/main/README.md#各设备安装指南)。

- Windows x64：`MyHKU.Setup.0.4.1-beta.exe`（安装版，支持识别旧目录覆盖升级）或 `MyHKU.0.4.1-beta.exe`（便携版）。
- Mac Apple Silicon：`MyHKU-0.4.1-beta-arm64.dmg` 或 `MyHKU-0.4.1-beta-arm64-mac.zip`。
- Android 8.0+：`app-release.apk`（`versionCode` 升至 16，沿用固定发布签名，可在 v0.1.4-alpha 及之后版本上直接覆盖升级）；`app-release.aab` 仅用于商店分发。
- `SHA256SUMS.txt` 提供全部发布产物的 SHA-256 校验值。

本版本为 Beta 预发布版本。macOS 默认采用 ad-hoc 签名，未经 Apple 公证；Windows 尚未使用发布者证书签名。请仅从本仓库 GitHub Releases 下载并核对 `SHA256SUMS.txt`。学校官方系统中的信息始终为最终依据。
