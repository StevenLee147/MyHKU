# MyHKU v0.2.3-alpha

本次更新重点修复 SIS 近期多周课表抓取为空、切换周次未就绪即提取以及历史缓存周次偏移的问题，并同步加固桌面端与 Android 端的课表分区缓存保护。

## 核心修复与改进

- **SIS 页面完整加载补抓与未就绪缓存保护**：修复桌面端官方窗口在 `dom-ready` 阶段单次执行连接器时 SIS 课表子框架尚未渲染完成导致抓空的问题，新增 `did-finish-load` 完成态补抓；在文档或子框架未完成加载且提取结果为空时，禁止发送 `replaceFields: ['schedule']` 或提前标记周区间已缓存，并同步对齐 Android 原生 `mergeSisPayload` 合并保护，防止局部加载或访问非课表菜单页清空已有课表缓存。
- **确定性周次切换与多步对齐**：桌面端 `myhku-schedule-week` 移除固定 `1200ms` 盲等定时器，改为读取 SIS 页面当前渲染周次并按目标周（`targetStartIso`）执行有界多步翻周、等待框架加载空闲后再提取并通知前端刷新。
- **SIS 课表 DOM 解析与双向多周预抓增强**：兼容单日期 `Week of DD/MM/YYYY` 标题、带日期列头、`12 小时制 AM/PM` 与 `9:30` 短时钟格式、时间在前/课程代码在后的单元格排版，以及时间轴行头 + `rowSpan` 兜底推断；同时遍历 `iframe` 与 `frame` 子文档，并在同步时自动向后预抓 4 周、向前预抓 2 周。
- **香港当前周基准锚定与自动补抓**：修复课表页在存在早期学期缓存周次时默认停留在旧周导致近期周显示为空的问题；桌面实时模式固定以香港时区当前自然周为默认「本周」基准，若当前周尚未缓存则在 SIS 已连接时自动后台补抓。

## 下载与安装

安装包见 [README 下载与设备对应](https://github.com/StevenLee147/MyHKU/blob/main/README.md#下载与设备对应)，详细步骤见 [各设备安装指南](https://github.com/StevenLee147/MyHKU/blob/main/README.md#各设备安装指南)。

- Windows x64：`MyHKU.Setup.0.2.3-alpha.exe`（安装版，支持识别旧目录覆盖升级）或 `MyHKU.0.2.3-alpha.exe`（便携版）。
- Mac Apple Silicon：`MyHKU-0.2.3-alpha-arm64.dmg` 或 `MyHKU-0.2.3-alpha-arm64-mac.zip`。
- Android 8.0+：`app-release.apk`（`versionCode` 升至 8，沿用固定发布签名，可在 v0.1.4-alpha 及之后版本上直接覆盖升级）；`app-release.aab` 仅用于商店分发。
- `SHA256SUMS.txt` 提供全部发布产物的 SHA-256 校验值。

本版本为 Alpha 预发布版本。macOS 默认采用 ad-hoc 签名，未经 Apple 公证；Windows 尚未使用发布者证书签名。请仅从本仓库 GitHub Releases 下载并核对 `SHA256SUMS.txt`。学校官方系统中的信息始终为最终依据。
