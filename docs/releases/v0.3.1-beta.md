# MyHKU v0.3.1-beta

本次更新重点增强桌面端后台常驻体验与全局键盘交互效率，新增桌面端系统托盘与最小化后台守护、全局交互式命令面板（`Ctrl+K` / `⌘K`），以及首页「正在上课 / 下一节课」实时倒计时聚焦卡片。

## 核心新增与改进

- **桌面端系统托盘常驻与后台守护**：Windows 与 macOS 桌面端新增系统托盘菜单，实时同步展示「下一节课 / 正在上课」与「最近截止 DDL」，支持一键显示主窗口、立即同步 HKU 数据与完全退出；设置页提供「关闭窗口时最小化到托盘」开关，开启后关闭主窗口可隐藏至托盘持续守护每日刷新与本地提醒。
- **交互式快捷命令面板 (`Ctrl+K` / `⌘K`)**：任意页面按下快捷键或点击顶栏搜索框快捷键徽章即可唤起原生 `<dialog>` 命令面板，支持方向键导航与 IME 安全回车检索并直达课程、未完成作业/自建倒计时、课程资料，以及一键执行同步、导出 `.ics`、新建倒计时、明暗主题与中英文切换。
- **首页「正在上课 / 下一节课」实时聚焦卡片**：基于香港时区（`Asia/Hong_Kong`）跨天检索未来 7 天课表，上课时显示剩余分钟数与 GPU 合成层平滑进度条（`transform: scaleX`），课前实时计算开课倒计时与教室位置，点击直达周课表。

## 下载与安装

安装包见 [README 下载与设备对应](https://github.com/StevenLee147/MyHKU/blob/main/README.md#下载与设备对应)，详细步骤见 [各设备安装指南](https://github.com/StevenLee147/MyHKU/blob/main/README.md#各设备安装指南)。

- Windows x64：`MyHKU.Setup.0.3.1-beta.exe`（安装版，支持识别旧目录覆盖升级）或 `MyHKU.0.3.1-beta.exe`（便携版）。
- Mac Apple Silicon：`MyHKU-0.3.1-beta-arm64.dmg` 或 `MyHKU-0.3.1-beta-arm64-mac.zip`。
- Android 8.0+：`app-release.apk`（`versionCode` 升至 14，沿用固定发布签名，可在 v0.1.4-alpha 及之后版本上直接覆盖升级）；`app-release.aab` 仅用于商店分发。
- `SHA256SUMS.txt` 提供全部发布产物的 SHA-256 校验值。

本版本为 Beta 预发布版本。macOS 默认采用 ad-hoc 签名，未经 Apple 公证；Windows 尚未使用发布者证书签名。请仅从本仓库 GitHub Releases 下载并核对 `SHA256SUMS.txt`。学校官方系统中的信息始终为最终依据。
