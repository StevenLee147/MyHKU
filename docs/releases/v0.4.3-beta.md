# MyHKU v0.4.3-beta

本次更新全面升级课程资料本地管理工作流，新增自定义课程资料总目录、按「课程代码 / 资料分类」自动建夹归档、本地已存目录智能索引与远端文件版本更新检测，并提供醒目的新增/更新提示与一键批量同步下载。

## 核心新增与改进

- **自定义课程资料储存目录（新老用户全覆盖）**：首次配置账户引导页、课程资料页顶部配置栏以及系统设置页均新增「课程资料储存目录」选择器与一键打开目录入口，支持自由指定专属课程总文件夹（如 `HKU_Courses`）并随时切换或恢复默认目录。
- **按课程与分类多级智能建夹归档**：下载引擎新增 `课程 + 分类归档` 模式，一级目录自动提取规范课程代码（如 `GLIS1901`、`GLIS1903`、`CAES9920`），二级目录自动识别 `Course Information`、`Lecture Notes` / `Lecture Slides`、`Annotated Slides`、`Tutorials`、`Python Labs`、`Assignments`、`Study_Guides`、`Mock Exam`、`Quiz Review`、`Seminar`、`Final Project` 等分类，并智能复用用户课程目录下已有的同名或近义子文件夹（如已有 `Tutorial` 或 `Lecture Notes` 时自动归入其中，不产生重复冗余目录）；同时保留「仅按课程归档」与「单层目录平铺」可选模式。
- **本地目录索引、版本更新检测与一键同步下载**：支持递归扫描现有课程目录自动识别已存文件，结合快照差异与 Moodle 远端资源修订号 / `ETag` / `Last-Modified` / 文件大小探测，在课程资料页顶部横幅、通知中心及单行卡片精准提示哪些文件**有更新**、哪些文件为**新增 NEW**；提供「一键下载新增与更新」全局同步按钮与单文件「一键更新」原子覆盖机制（先写入临时文件校验成功后再原地更新旧版课件，避免生成重复 `(1)` 副本）。

## 下载与安装

安装包见 [README 下载与设备对应](https://github.com/StevenLee147/MyHKU/blob/main/README.md#下载与设备对应)，详细步骤见 [各设备安装指南](https://github.com/StevenLee147/MyHKU/blob/main/README.md#各设备安装指南)。

- Windows x64：`MyHKU.Setup.0.4.3-beta.exe`（安装版，支持识别旧目录覆盖升级）或 `MyHKU.0.4.3-beta.exe`（便携版）。
- Mac Apple Silicon：`MyHKU-0.4.3-beta-arm64.dmg` 或 `MyHKU-0.4.3-beta-arm64-mac.zip`。
- Android 8.0+：`app-release.apk`（`versionCode` 升至 18，沿用固定发布签名，可在 v0.1.4-alpha 及之后版本上直接覆盖升级）；`app-release.aab` 仅用于商店分发。
- `SHA256SUMS.txt` 提供全部发布产物的 SHA-256 校验值。

本版本为 Beta 预发布版本。macOS 默认采用 ad-hoc 签名，未经 Apple 公证；Windows 尚未使用发布者证书签名。请仅从本仓库 GitHub Releases 下载并核对 `SHA256SUMS.txt`。学校官方系统中的信息始终为最终依据。
