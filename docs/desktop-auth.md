# 桌面登录流程

Portal、SIS、Moodle 各保留一个固定服务记录，共享原有 `persist:myhku-hku` 分区。自动 SSO 操作依次进行；跳转到 Microsoft、ADFS 或 CAS 后仍属于原服务。成功、失败、超时或需要用户验证时均释放自动操作队列，其他服务继续连接；等待用户操作的窗口仍被观察，验证完成后可直接确认成功或重新排队继续官方跳转。恢复原流程保留已执行动作，不重复提交凭据。启动、重复点击登录、刷新均复用记录。Windows 关闭仪表盘会退出后台会话及 bridge，再次启动只允许一个应用实例。

DOM 可用、导航提交、子框架完成等事件立即触发检查，并每 500 毫秒兜底检查。直接检查当前 WebFrameMain，不等待整个页面、图片或子框架加载结束；隐藏窗口禁用后台节流。自动点击 SIS 的 Portal Login、Moodle 的 HKU Portal User；只读检查仅传入邮箱提示，只有取得队列执行权后才向身份服务发送密码，绝不填写 SIS/Moodle 访客表单。CAS AAD 的邮箱框即使是 `type=text` 也保留完整邮箱，并点击其 `login_btn` 执行官方登录脚本；只有明确的旧版 UID 框才使用邮箱前缀。双字段身份表单同时填写用户名和密码；同文档同一步只提交一次，同一流程每一步最多自动尝试两次。正在回调或尚未渲染输入框的页面继续等待，不直接提示 2FA。

成功必须有官方页面的登录后 DOM 标记，且两次观察至少相隔 250 毫秒；单独的业务网址、空白页和中间跳转不能证明首次登录成功。覆盖真实 Student Portal 隐藏菜单中的 CAS `PortalLogout` 链接、SIS 的 PeopleSoft `pthdr2signout` 菜单和课表控件、Moodle 用户/课程区域。已确认登录后的普通业务跳转不会将连接状态改回检查中，出现实际登录表单或验证挑战才重新认证。用户搜索框、Authenticator 帮助文字、业务错误提示和可选登录链接不能覆盖已登录标记；活跃密码表单和 Moodle 访客标记不能被误认成功。CAS 的明确登录成功提示只用于继续目标服务，不直接标记服务已连接。

SIS 新会话、刷新和重试均先加载 Student Portal，并点击页面实际提供的 SIS 入口，避免过期会话直接访问课表触发阻塞式登录弹窗。遇到“请从 Portal 登录”或 CAS 登录错误页，也会回到 Student Portal。接管官方新窗口时保留浏览器提供的来源策略和表单 POST，避免丢失 Portal 来源或登录回调数据。SIS 首页确认登录后立即释放队列，再点击页面实际提供的 My Weekly Schedule；课表加载不能拖延登录成功。Portal 成功不能单独证明 SIS 成功；SIS 的嵌套、跨域官方子页面并行检查，已成功的子页面无需等待慢兄弟框架。身份验证挑战、明确凭据错误或没有保存账户时立即显示官方窗口，其他需要手动操作的页面给予 20 秒恢复时间，未完成流程在 90 秒后显示实际页面供检查并释放队列。

页面检测设置 3 秒执行期限；跳转立即废弃旧检测并释放检查锁，迟到的结果不能改写新文档或新账户的状态。90 秒提示独立于页面加载和检测任务，窗口启动失败和渲染器退出也会释放队列。导航日志仅追加检测状态及动作名称，不保存页面文字、表单值或凭据。

官方页面加载失败后仍保留只读检查，手动刷新或登录成功可以恢复连接。仪表盘打开服务时复用同一服务记录；未连接时打开的验证窗口成功后自动收起，已连接后主动打开的课程或服务页面则保留窗口。窗口收起后继续保留会话与数据同步。

官方退出链接或明确的退出成功提示会将该服务标为未连接，并停止自动填写密码；后续点击连接才重启自动登录，用户也可在原窗口手动登录。普通业务页面的加载等待不会覆盖已经确认的连接。

登录状态由主进程维护，仪表盘通过事件更新，并每 5 秒获取当前状态以恢复遗漏事件。每个服务状态带有递增版本，旧 IPC 响应不能覆盖新事件；验证横幅和侧栏也由同一份状态决定，遗漏成功事件后能一起恢复。登录成功无需等到课程爬取结束；规范化数据提交完成后再通知界面读取数据。刷新不会重载仍在认证中的窗口。已连接的服务不会因再次点登录而新开会话。

官方窗口不加载仪表盘的账户管理 preload；账户 IPC 只接受仪表盘主框架请求。注销或切换邮箱时，先废弃记录并销毁旧窗口，再清理官方分区存储和 HTTP 认证缓存，防止旧页面回调重新建立已退出账户的会话。

运行 `npm run test:desktop-auth`：包含队列单元测试、真实 Chromium DOM 测试和生产主进程/preload 集成测试。集成测试使用独立临时配置、随机本机端口及本地官方页面替身；仅使用保留示例域名的虚构账户，不读取已安装版账户或连接真实 HKU 登录服务。

本地替身测试覆盖 Portal 图片永不完成时的成功延迟与后续登录、慢 CAS 回调、已有 SSO、访客入口、重复请求、超时/MFA 后队列继续、迟到 CAS 恢复、状态响应乱序、遗漏成功事件后的横幅恢复，以及成功页误判、Portal 的 SIS 入口、跨域课表、加载失败恢复和手动验证窗口自动收起。真实 HKU 的 MFA、学校页面结构及实际账户权限仍需在更新后的客户端验证。
